# Salon Template

Готовый универсальный шаблон TANEM для салонов.

## Структура
- `index.html` — базовая разметка и выбор mobile/desktop runtime.
- `mobile.js` — единый мобильный runtime: portrait, landscape-phone, галерея, услуги, команда, отзывы, запись, медиа и языки.
- `desktop.js` — единый desktop/MacBook runtime и один итоговый stylesheet.
- `logo-placeholder.svg` — заглушка логотипа.
- `media-placeholder.svg` — заглушка фото/медиа.

Промежуточные версии, fix/patch-файлы и старые загрузчики удалены. При создании сайта нового салона меняются только данные и медиа; геометрия, адаптивность и механики шаблона остаются без изменений.
