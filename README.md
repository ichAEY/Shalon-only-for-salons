# TANEM — Shalon Only for Salons

Единый production-шаблон TANEM для салонов. Индивидуальные мастера собираются в отдельном шаблоне.

## Принцип

Новый сайт создаётся данными, а не ручной переделкой интерфейса:

```text
данные салона + фотографии
            ↓
       site-data.mjs
            ↓
   универсальный Salon Engine
            ↓
 готовый mobile + desktop сайт
```

При создании обычного клиентского сайта не нужно менять `app/salon-template.tsx` или `app/template.css`.

## Что уже умеет Salon Engine

- отдельные, согласованные mobile и desktop-композиции;
- мобильная компоновка сохраняется при повороте телефона;
- заставка, шапка, навигация и переключение языков;
- главный экран с фотографией или видео;
- автоматический статус «открыто / закрыто» по часовому поясу;
- портфолио, категории галереи и полноэкранный просмотр;
- любое количество категорий услуг;
- прямая онлайн-запись либо запись через контакты;
- фиксированная карточка выбора услуги на desktop;
- блок о салоне, команда и карточки специалистов;
- отзывы на нативной прокручиваемой ленте без бесконечной перерисовки;
- контакты, карта, маршрут и системная плашка TANEM;
- локальные шрифты, reduced-motion и блокировка прокрутки модальных окон;
- статический экспорт для GitHub Pages.

## Где заполнять данные

- `site-data.mjs` — все тексты, услуги, специалисты, контакты, ссылки и пути к медиа;
- `public/` — фотографии, видео, логотип и favicon;
- `RULES.md` — обязательные правила заполнения;
- `FACTORY.md` — последовательность выпуска нового сайта.

## Проверка

```bash
npm ci
npm run check
```

Локальная разработка:

```bash
npm run dev
```

Пустой шаблон намеренно показывает нейтральные заглушки. Они не являются данными клиента и исчезают после заполнения `site-data.mjs`.
