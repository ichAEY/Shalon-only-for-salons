# Salon Template

Готовый универсальный шаблон TANEM для салонов.

## Структура
- `index.html` — базовая разметка и выбор mobile/desktop runtime.
- `mobile.js` — единый мобильный runtime: portrait, landscape-phone, галерея, услуги, команда, отзывы, запись, медиа и языки.
- `desktop.js` — единый desktop/MacBook runtime и один итоговый stylesheet.
- `logo-placeholder.svg` — заглушка логотипа.
- `media-placeholder.svg` — заглушка фото/медиа.

Промежуточные версии, fix/patch-файлы и старые загрузчики удалены. При создании сайта нового салона меняются только данные и медиа; геометрия, адаптивность и механики шаблона остаются без изменений.


## Правила заполнения салона
- Языки выбираются по стране салона: для России — только `RU / EN`; для Армении — `RU / EN / HY`. Армянский язык нельзя автоматически добавлять российским салонам.
- Статус работы и город в hero должны использовать одну компактную визуальную механику на mobile и desktop.
- Если у салона есть видео, его можно использовать первым элементом портфолио/галереи вместо hero; hero-медиа задаётся отдельно из салонных фотографий.
- Если в команде больше четырёх подтверждённых мастеров, desktop показывает четыре карточки одновременно, остальные доступны горизонтальным перелистыванием с явными элементами управления.
- Имена, должности, рейтинг, количество отзывов, услуги, цены и контакты нельзя придумывать. Используются только подтверждённые данные.
- Рейтинг отображается с заполненной жёлтой звездой/звёздами. В счётчике отзывов показывается подтверждённое количество отзывов; отдельное количество оценок не выводится, если оно не требуется.
- Лента отзывов должна быть бесконечной и бесшовной.
