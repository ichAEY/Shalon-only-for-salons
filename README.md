# Shablon Only for Salons

Чистый универсальный шаблон TANEM для салонов.

Источник интерфейса: последняя рабочая версия Esmeralda v69, commit `bb42cc0`.

В этой версии не создавался новый дизайн. Мобильная и desktop/MacBook версии перенесены из эталона с сохранением структуры, адаптивности, анимаций, галереи, услуг, команды, отзывов, записи, контактов и языкового переключателя.

Удалены только данные конкретного салона: название, адрес, телефон, ссылки, реальные отзывы, мастера, услуги и клиентские медиа. Вместо них используются нейтральные заполнители: `Название салона`, `Адрес салона`, `Услуга 01`, `Мастер 1`, `placeholder.svg`.

При создании нового сайта заменяются только данные и медиа. Структуру v69 и responsive-логику менять нельзя без отдельной задачи.
