# Shablon Only for Salons

Шаблон TANEM для салонов на основе утверждённой версии Esmeralda v69.

Сохранены mobile, landscape-phone и desktop/MacBook структура, размеры, отступы, анимации и механики v69. Меняется только слой данных клиента.

В шаблоне нет реального рейтинга, графика, телефона, адреса, отзывов или клиентских медиа. Для сохранения геометрии используются явные заполнители SALON NAME, Услуга 01, Мастер 1 и SVG-заглушки.

Исторические технические ID и CSS-классы сохранены специально: они являются частью рабочего runtime v69 и не показываются пользователю.
