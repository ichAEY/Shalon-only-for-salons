# TANEM Salon Factory

## Входные данные

Для каждого салона нужны:

- целевой GitHub-репозиторий;
- подтверждённое название;
- город, адрес, режим работы и часовой пояс;
- телефон и доступные каналы связи;
- ссылка онлайн-записи, если она существует;
- услуги, категории, цены и длительность;
- сотрудники и их направления;
- рейтинг, количество и тексты проверенных отзывов;
- фотографии, логотип и при необходимости видео;
- ссылки карты, маршрута и отзывов.

## Выпуск сайта

1. Взять текущий `main` этого репозитория.
2. Загрузить оптимизированные медиа в `public/`.
3. Заполнить только `site-data.mjs`.
4. Установить `template.preview: false` после внесения реальных данных.
5. Указать правильный `NEXT_PUBLIC_BASE_PATH` для GitHub Pages либо оставить пустым для собственного домена.
6. Запустить `npm run check`.
7. Проверить минимум четыре режима: iPhone portrait, iPhone landscape, desktop 1366×768 и desktop 1440×900.
8. Проверить меню, языки, все способы записи, категории услуг, галерею, специалистов, отзывы и маршрут.
9. Публиковать только после зелёной проверки.

## Если найден общий баг

Баг исправляется здесь, в Salon Engine. Нельзя добавлять поверх клиентского сайта отдельный патч или второй runtime. После исправления запускаются lint, validator, production build и тесты, затем новая версия переносится в клиентские репозитории.

## Что не копируется из сайтов клиентов

- старые workflows и одноразовые скрипты;
- история исправляющих файлов;
- аналитика другого клиента;
- домены, телефоны и ссылки;
- тексты, услуги, отзывы и переводы;
- фотографии, видео и логотипы;
- имена CSS/JS, связанные с конкретным клиентом.
