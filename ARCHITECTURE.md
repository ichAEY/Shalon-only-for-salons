# Архитектура

## Один поток данных

`site-data.mjs` импортируется серверным layout и клиентским компонентом. Metadata собирается на этапе статического экспорта, а интерфейс получает те же данные без второго источника правды.

## Один интерфейс

`app/salon-template.tsx` содержит семантическую структуру всех разделов и состояния окон. `app/template.css` отвечает за обе композиции.

Desktop включается только при трёх условиях одновременно: ширина от 1024 px, точный указатель и поддержка hover. Поэтому поворот телефона не переключает сайт в desktop-режим.

## Ограниченная динамика

В runtime остаются только необходимые действия:

- выбор языка;
- статус работы раз в минуту;
- один обработчик прокрутки, объединённый через `requestAnimationFrame`;
- одноразовый `IntersectionObserver` для появления секций;
- состояние меню, записи, галереи и карточки специалиста.

Непрерывных анимационных циклов, DOM-наблюдателей и динамической вставки стилей нет.

## Развёртывание

Next.js создаёт полностью статическую папку `out/`. Workflow сначала запускает lint, validator, build и тесты. Публикация выполняется только из `main` и только если GitHub Pages уже включён в настройках репозитория.
